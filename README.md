# Pension Felix – Gästinnen‑Feedback (GitHub Pages)

Ein‑Datei‑Formular mit Wiener Schmäh. **Senden per FormSubmit** (Server übernimmt) und **Mail‑Fallback**.

## So veröffentlichst du das als GitHub Page (https://)

1. **Neue Repo erstellen** (z. B. `pension-felix-form`).
2. Diese vier Dateien hochladen:
   - `index.html`
   - `thankyou.html`
   - `.nojekyll`
   - `README.md` (optional)
3. Gehe zu **Settings → Pages**:
   - *Source:* `Deploy from a branch`
   - *Branch:* `main` / `/ (root)` → **Save**
4. Warte kurz, dann steht oben die **Page‑URL** (z. B. `https://deinname.github.io/pension-felix-form/`).

**Hinweis:** Beim ersten Submit schickt FormSubmit eine Verifizierungs‑Mail an `felix.taglieber@gmx.at`. Einmal bestätigen, danach kommen alle Einsendungen automatisch an.

Viel Spaß & gutes Gästinnen‑Feedback! ✦
